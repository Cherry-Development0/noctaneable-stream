## Overview

Noctaneable is a lightweight desktop screen sharing utility designed for direct streaming between users without third-party servers storing or handling your media feeds. It provides smooth 60 FPS video capture with system sound and microphone audio at controlled bandwidth rates.

---

## Features

### Display and Window Sharing
Select between streaming entire monitors or specific running application windows. Includes options for desktop audio capture and inline microphone controls.

### Bandwidth and Framerate Optimization
Video bitrates are tuned to operate efficiently between 0.2 Mbps and 1.8 Mbps with a maximum cap of 2.0 Mbps to prevent network congestion. Standardized on 60 FPS with selectable 720p and 1080p resolutions.

Preset performance tiers include:
- Eco: Low-bitrate streaming for unstable or limited connections.
- Balanced: Default profile providing clear 60 FPS video for general use and gaming.
- High: Higher bit allocation for sharp text clarity and fast motion.

### Peer-to-Peer Rooms
Connect directly with others using simple 8-character room codes. Streams travel directly between participants without accounts, sign-ins, or registration required.

### Picture-in-Picture and Always on Top
Pop any stream into a compact, borderless floating mini-player. The window can be pinned on top of games and other desktop applications.

## Installation

1. Download the latest installer from the Releases section.
2. Run `Noctaneable_Setup.exe` to install the application.
3. Launch Noctaneable, create or join a room using a room key, and start sharing.

If you already have the application installed it will automatically receive updates whenever there is one

## Requirements

- Operating System: Windows 10 or Windows 11 (64-bit)
- Network: Broadband internet connection
